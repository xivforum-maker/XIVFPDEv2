\chapter*{About this test edition}
\addcontentsline{toc}{chapter}{About this test edition}

This test edition demonstrates the proposed typographic structure for the final
\emph{Book of Abstracts} of the XIV Forum of Partial Differential Equations.
The wording of the abstracts is reproduced from the authors' submitted PDF files;
only typographic markup and page layout have been standardized.

The sample deliberately combines contributions with different levels of
mathematical notation and bibliography complexity. Each abstract begins on a
new page so that the layout can be reviewed independently before the complete
collection is prepared.
